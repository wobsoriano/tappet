# tappet

End-to-end testing for mobile apps with the Playwright test runner. tappet drives a booted simulator or emulator through Callstack [`agent-device`](https://agent-device.dev/) and launches no browser.

```sh
pnpm add -D tappet @playwright/test
```

tappet is experimental and its API will change between minor versions.

The documentation lives in the repository. Start with [the README](https://github.com/wobsoriano/tappet#readme), then [Basics](https://github.com/wobsoriano/tappet/blob/main/docs/basics.md), [Configuration](https://github.com/wobsoriano/tappet/blob/main/docs/configuration.md), [Locators](https://github.com/wobsoriano/tappet/blob/main/docs/locators.md), [Assertions](https://github.com/wobsoriano/tappet/blob/main/docs/assertions.md), and [Lifecycle](https://github.com/wobsoriano/tappet/blob/main/docs/lifecycle.md).
